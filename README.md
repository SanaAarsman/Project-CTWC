# Project-CTWC

## Project overview
This project explores the history and evolution of the Classic Tetris World Championship (CTWC) through data analysis.

The current focus is on:
- tournament structure over time
- playstyle evolution (`DAS`, `Tap`, `Roll`)
- performance trends across years
- relationships between score, total lines, and playstyle

## Current status
So far, I have completed:
- dataset understanding
- missing-value investigation
- univariate EDA
- core bivariate EDA

## Main finding so far
The strongest pattern so far is that CTWC performance trends cannot be read as simple year-to-year improvement, because the dataset also reflects major changes in tournament structure and competitive playstyle over time.

A particularly important part of this is that the pandemic years introduced major changes in tournament format, which strongly affects how some years should be interpreted and compared.
